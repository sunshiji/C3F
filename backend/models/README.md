# OCR 模型权重目录 / OCR Model Weights Directory

将 EasyOCR 模型权重文件（`.pth`）放到本目录后，后端启动时会直接从此处加载，
**无需**联网下载。

## 下载模型

在有网络的环境中运行以下命令，将所有支持的模型权重下载到本目录：

```bash
python backend/download_models.py
```

下载完成后将目录中的 `.pth` 文件保留在此处。部署到离线服务器时，
将整个 `models/` 目录一并拷贝过去即可。

## 支持的语种

| 分组 | EasyOCR 代码 | 语种名称 |
|------|-------------|---------|
| CJK  | ch_sim, en, ja, ko | 简体中文、英文、日文、韩文 |
| 繁中  | ch_tra, en | 繁体中文、英文 |
| 阿拉伯 | ar, en | 阿拉伯文、英文 |
| 天城体 | hi, en | 印地语、英文 |
| 西里尔 | ru, en | 俄文、英文 |
| 泰文  | th, en | 泰语、英文 |
| 孟加拉 | bn, en | 孟加拉文、英文 |
| 卡纳达 | kn, en | 卡纳达文、英文 |
| 泰卢固 | te, en | 泰卢固文、英文 |
| 古吉拉特 | gu, en | 古吉拉特文、英文 |
| 旁遮普 | pa, en | 旁遮普文（古鲁穆奇）、英文 |
| 泰米尔 | ta, en | 泰米尔文、英文 |

> **注**：希腊文、希伯来文、柬埔寨文（高棉文）、藏文、蒙古文和奥里亚文
> 不在 EasyOCR 的模型范围内，系统将通过 Unicode 字符范围检测直接识别这些文种，
> 无需对应的 OCR 权重文件。
